One-time Google Sheet setup

Paste the Apps Script Web App URL and the same token used in apps_script/Code.gs.

Quick setup: Google Sheet → Extensions → Apps Script → paste apps_script/Code.gs → change TOKEN → Deploy as Web App → copy the /exec URL here.
The URL and token are stored privately on the server PC only under Local AppData. They are never saved in the shared project/NAS folder, product PDFs, or public research.
